## 🧩 1. Incorporação dos Princípios da POO

Pretendo incorporar os princípios da Programação Orientada a Objetos (POO) no projeto de forma prática e organizada, garantindo uma estrutura modular, reutilizável e de fácil manutenção.  
Aplicarei os conceitos fundamentais da POO — **abstração**, **encapsulamento**, **herança** e **polimorfismo**.

- **Abstração:** Representar apenas as características essenciais de cada elemento do sistema, eliminando detalhes desnecessários e tornando o código mais simples e compreensível.  
- **Encapsulamento:** Proteger os dados internos das classes, restringindo o acesso direto aos atributos e garantindo integridade e segurança das informações.  
- **Herança:** Criar classes derivadas que aproveitam atributos e métodos de classes mais gerais, reduzindo repetição de código e promovendo uma estrutura hierárquica clara.  
- **Polimorfismo:** Permitir que métodos com o mesmo nome apresentem comportamentos diferentes conforme o contexto, aumentando a flexibilidade e escalabilidade do sistema.  

Essa abordagem baseada em POO facilitará futuras atualizações, correções e expansões, promovendo um código limpo, sustentável e de fácil compreensão.

## ⚙️ 2. Componentes Tecnológicos

Para o desenvolvimento da solução, utilizarei:

## 👥 3. Usuários do Sistema

- **Usuários Finais:** Consumidores que utilizarão o sistema de forma prática e direta.  
- **Usuários Administrativos:** Responsáveis por funções de gestão e controle.  
- **Usuários Operacionais:** Executam tarefas específicas e rotineiras no sistema.

📌 **Impacto Humano:**  
A colaboração entre essas categorias garante um sistema eficiente, funcional e alinhado às necessidades dos usuários e aos objetivos da organização.

## 🏗️ 4. Arquitetura do Sistema

O desenvolvimento será estruturado em **camadas** seguindo o padrão **MVC (Model-View-Controller)**:

1. **Model:** Criação do banco de dados e definição das regras de negócio.  
2. **Controller:** Responsável pela integração entre o modelo e a interface.  
3. **View:** Desenvolvimento da interface do usuário, priorizando design e usabilidade.
